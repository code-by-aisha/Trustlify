# TRUSTLIFY — FINAL VISUAL DESIGN SYSTEM V1
## Figma Prototype + Website Master Visual Direction
### Locked Theme: Evidence Noir / Violet + Lime

---

## 01 — DESIGN DECISION

Trustlify's visual direction is LOCKED.

**Core style:** Evidence Noir — a dark editorial + technical investigation aesthetic.

The visual language combines:
- Dala-style spatial darkness, oversized editorial typography and floating visual fragments.
- The dark technical-network/depth feeling of the decentralized-AI reference.
- Monad-style editorial hierarchy, diagrams and structured information.
- The selected **black + violet + acid-lime + white** palette.

References are inspiration only. Trustlify must remain original.

---

## 02 — BRAND FEEL

Intelligent • investigative • premium • confident • modern • experimental • trustworthy • spatial • evidence-driven.

Avoid:
- generic AI gradients
- blue/cyan SaaS styling
- robot/brain imagery
- excessive glassmorphism
- crypto/cyberpunk aesthetics
- crowded dashboards
- stock photography
- decorative animation with no meaning

The product should feel like **intelligence infrastructure + investigation tool + editorial technology**.

---

## 03 — CORE VISUAL METAPHOR

### INFORMATION → EVIDENCE → CONFIDENCE

The visual story begins with fragmented online information:
post • screenshot • URL • comment • deadline • logo • message • PDF

Then:
**Claims → Sources → Evidence → Verification → Decision**

The interface should visibly move from fragmented information to organized evidence.

---

## 04 — COLOR SYSTEM

### Primary
- Void Black: `#0A0A0F`
- Deep Violet: `#1A1025`
- Electric Violet: `#7C3AED`
- Acid Lime: `#A3FF12`
- Bone White: `#F8F9FA`
- Soft Gray: `#A1A1AA`
- Deep Gray: `#52525B`

### Semantic
- Verified: lime
- Caution/conflict: `#F5B942`
- High risk: `#FF4D5E`
- Unverified: neutral gray

Brand accents and status colors must remain visually distinct.

Use dark surfaces as the dominant visual field. Lime is rare and meaningful.

---

## 05 — TYPOGRAPHY

### Display / Hero
Use a distinctive editorial display typeface: refined, high personality, not a common AI/SaaS geometric font. Prefer weight 400 and tight tracking.

### Body / UI
Use one clean technical sans or mono-leaning family, e.g. IBM Plex Mono, JetBrains Mono, Geist Mono or Space Mono.

### Hierarchy
- Hero: 72–120px desktop
- Section: 48–72px
- Subsection: 28–40px
- Body: 16–20px
- Metadata: 12–14px
- Buttons: 14–16px

Do not use bold everywhere. Build hierarchy through scale, whitespace and contrast.

---

## 06 — LAYOUT + SHAPES

Desktop max-width: 1280–1440px.
Large section spacing: 96–160px.

Landing page: editorial/asymmetrical compositions; prefer text + visual rather than repetitive card grids.

Product UI: denser because evidence requires information density.

Shapes:
- rounded investigation cards
- thin borders
- occasional pill labels
- nodes/circles for evidence graph
- cards around 20–28px radius
- pills 9999px

Avoid making everything a pill.

---

## 08 — MOTION

Motion must explain meaning.

### Ambient
Very subtle particles, data points and background drift.

### Parallax
Separate depth layers:
1. background field
2. input fragments
3. claim/source cards
4. evidence connections
5. decision

### Scroll transformation
As the user scrolls, fragmented elements become organized and the graph resolves into a clean Trustlify decision.

### Microinteraction
Hover/tap on an evidence fragment:
- brighten it
- reveal source label
- highlight related evidence
- softly illuminate connected nodes

Use fade, slide, draw, connect, reveal.
Avoid bounce, spin, elastic overshoot, flashy 3D and constant glow.

## 09 — LANDING PAGE STRUCTURE

### 01 Hero
Information is everywhere. Confidence isn't.

### 02 Problem
**Seeing information is easy. Knowing what to trust isn't.**
Show the manual journey:
Post → Search → Official site → Another source → Deadline → Eligibility → Reviews → Decision

### 03 How Trustlify Works
Understand → Investigate → Compare → Verify → Decide

### 04 Evidence Engine
**AI doesn't become the source of truth.**
Show Claim → Official source → Independent source → Public evidence → Verification.
Separate **FACT** from **INTERPRETATION**.

### 05 Student Intelligence
**Not only “Is it real?” Also “Does it fit me?”**
Education • Skills • Location • Experience • Relevance.

### 06 Currentness
**Real once doesn't mean current now.**
Timeline: Published → Updated → Deadline → Current state.

### 07 Risk + Action
**Knowing the risk is only half the job.**
Verdict → Why → Safe next action.

### 08 Privacy
**Verify without exposing more than you need to.**
Show redaction of sensitive data before analysis.

### 09 Local Context
English • Urdu • Roman Urdu • Sindhi*.
*Enable/claim Sindhi after validation.

### 10 Impact / Proof
Use sourced Pakistan digital context + actual survey data + actual Trustlify pilot data. Never invent a scrolling/time statistic.

### 11 Why Trustlify
Investigate Anything • Evidence-Driven • Conflict Detection • Currentness • Student Match • Actionable Guidance.

### 12 About
**Trust should be earned through evidence.**
Mission, evidence-first philosophy, responsible AI, limits, student impact, roadmap.

### 13 Final CTA
**See something uncertain? Investigate it.**

## 24 — UNVERIFIED STATE
