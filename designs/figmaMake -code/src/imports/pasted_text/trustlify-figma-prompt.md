# TRUSTLIFY — FINAL FIGMA MAKE GENERATION PROMPT

Use the attached **Trustlify Visual Design System V1** as the primary design source of truth.

Use the attached visual references only as inspiration. Do not copy any reference directly.

Build a complete, high-fidelity, responsive, clickable Trustlify product prototype.

---

## 1. PRODUCT

Trustlify is an evidence-driven AI investigation platform.

It helps people investigate:
- websites
- links
- social posts
- screenshots
- PDFs
- messages
- scholarships
- internships
- jobs
- courses
- hackathons
- other online claims

The primary audience is students.

There are two user modes:

### Student
Personal profile + eligibility + relevance + investigation.

### General User
General online investigation without student matching.

Core product flow:

**INPUT → CLAIMS → SOURCES → EVIDENCE → VERIFICATION → DECISION → ACTION**

The design must make this flow visually obvious.

# 6. HERO PARALLAX SYSTEM

Create 5 visual depth layers.

### Layer 1 — Ambient
Tiny evidence particles, faint traces, subtle atmospheric noise.

### Layer 2 — Background fragments
Small posts, comments, URLs moving very slowly.

### Layer 3 — Main fragments
Larger screenshot/post/PDF/source cards.

### Layer 4 — Investigation network
Claim, source and evidence nodes.

### Layer 5 — Decision
Final Trustlify decision card.

Each layer should move at a different speed during scrolling.

Create depth without making the animation distracting.

---

# 7. HERO TRANSFORMATION

At the beginning:

**ONLINE NOISE**

Information fragments are disconnected.

As the user scrolls:

Fragments begin moving toward related claims.

Then:

**CLAIMS**

Connections begin appearing.

Then:

**SOURCES**

Official and independent sources become visible.

Then:

**EVIDENCE**

Evidence relationships draw between nodes.

Then:

**VERIFICATION**

A verification stage resolves the relationships.

Finally:

**DECISION**

Show a polished Trustlify decision card.

Example:

### VERIFY BEFORE APPLYING

Evidence strength: 62/100

Official source ✓
Independent confirmation ✓
Deadline conflict ⚠
Domain mismatch !

The final lime highlight should feel earned.
